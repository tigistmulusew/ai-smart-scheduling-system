# AI-Based Smart Class Scheduling System

An AI-based smart class scheduling system developed as a university project to automate and optimize academic scheduling while reducing scheduling conflicts.

##  Project Overview

The system addresses challenges associated with manual and spreadsheet-based class scheduling. It helps manage courses, instructors, classrooms, instructor preferences, and scheduling constraints to generate conflict-free academic schedules.

##  Objectives

- Automate the academic scheduling process
- Reduce scheduling conflicts and double-booked rooms
- Consider instructor availability and preferences
- Optimize classroom and academic resource allocation
- Provide transparent and efficient schedule management

##  Key Features

- User management and role-based access control
- Teacher preference management
- AI-powered scheduling engine
- Automatic conflict detection
- Instructor availability management
- Classroom and course management
- Interactive schedule visualization
- PDF schedule export
- Notifications for schedule updates
- Admin review and approval

##  AI & Multi-Agent Scheduling

The scheduling engine uses SPADE (Smart Python Agents for Distributed Environments) to implement autonomous software agents.

The system models key entities such as instructors, rooms, and the scheduler as agents that communicate and collaborate to generate conflict-free weekly schedules.
